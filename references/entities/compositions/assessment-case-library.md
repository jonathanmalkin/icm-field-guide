# Assessment case library

- **Composition:** Pipeline → Record Library
- **Use for:** audits, evaluations, compliance cases, inspections, and recurring reviews.
- **Flow:** instantiate case → collect evidence → apply checks → review judgment
  → publish approved findings into the case record.
- **Factory:** framework, scoring rules, evidence schema, and report template.
- **Product:** one isolated case with sources, findings, decisions, and remediation.
- **Human check:** approve findings and status transitions.
