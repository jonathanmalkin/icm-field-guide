# Application patterns

Patterns are orientation hypotheses for a recurring job, not canonical form
choices. Choose by the repeating unit; then confirm the form in
[ICM Architect's selection table](https://github.com/RinDig/icm-architect/blob/b20fb45063a564cf607b03526e206f519d174def/references/forms.md#selection).

**Route first:** CRM/ERP or system-of-record questions begin with
[system archetypes](../system-archetypes/README.md). Automation, multi-agent,
or autonomous-branching questions begin with
[operational overlays](../overlays/README.md).
