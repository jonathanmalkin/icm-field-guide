# ICM Field Guide entity library

Use this library to find an application by the kind of thing it is.

| Entity type | Question it answers |
|---|---|
| [Application patterns](application-patterns/README.md) | What recurring real-world job is being done? |
| [System archetypes](system-archetypes/README.md) | Is this shaped like a CRM, ERP, or another system of record? |
| [Overlays](overlays/README.md) | What cross-cutting concern changes the design? |
| [Compositions](compositions/README.md) | Which canonical forms recur together? |
| [Project examples](project-examples/README.md) | Which community-described project illustrates this? |
| [Tools and kits](../tools-and-kits.md) | Which concrete kit, decision aid, or implementation reference helps? |

Each entity is intentionally small and independently linkable. Canonical forms
and invariants remain upstream in ICM Architect.
