# Festival outreach kit

- **Pattern:** Acquisition and relationship flywheel
- **Forms:** per-festival Pipeline feeding a Record Library (one ledger of
  contacts and threads)
- **Repeating unit:** one festival campaign; inside it, one artist contact
- **ICM application:** festival URL → lineup → management or booking contact
  researched from source pages (each contact stored with the page it came
  from) → short intro drafted in the client's voice → one review list →
  client cuts, edits, approves → send from the client's own inbox → thread
  tracking, anyone who replies is skipped → follow-up about a week later
  through the same approval.
- **Key gates:** approval is a file the send step requires, not a habit; the
  send path is a fixed script the agent cannot edit or improvise around;
  repliers never receive follow-ups; domain deliverability (SPF/DKIM/DMARC)
  checked before the first batch.
- **Evidence:** builder-described shipped client kit; early result figures
  (more usable contacts than manual research, first positive replies) are
  source claims.
